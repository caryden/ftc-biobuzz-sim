# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Many of the people here are high school students. Be kind, be patient with beginners, and keep every discussion
suitable for a school setting. *FIRST*'s idea of Gracious Professionalism applies: compete hard, and help each other.

To report a problem, open an issue. For anything that shouldn't be public, say only that you have a report, and a
maintainer will give you a private channel. The maintainers can edit or remove comments, commits, and issues that
break these rules.
